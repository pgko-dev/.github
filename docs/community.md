# Maintaining community guidance

This repository contains shared contributor instructions, the vulnerability reporting policy, and the organization profile.

| File                | Update when                                                                         |
| ------------------- | ----------------------------------------------------------------------------------- |
| `CONTRIBUTING.md`   | Bug-report requirements, contribution expectations, or repository ownership changes |
| `SECURITY.md`       | Private reporting instructions change                                               |
| `profile/README.md` | The public project overview or its entry links change                               |
| `README.md`         | The document overview or navigation changes                                         |

Keep build commands, runtime versions, feature behavior, and deployment instructions in the owning repository. Link to its README or `docs/` instead of copying those details here.

When changing shared guidance, check relative links and the public repository links. Security reports should identify the affected repository and stay private during investigation.
