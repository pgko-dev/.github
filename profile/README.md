# [pgko](https://pgko.dev/)

A platform for sharing [UMIGURI](https://umgr.inonote.jp/en/) rhythm-game charts.

Explore the [public applications and shared packages](https://github.com/pgko-dev/pgko), read the [contribution guide](https://github.com/pgko-dev/.github/blob/main/CONTRIBUTING.md), or [report a vulnerability privately](https://github.com/pgko-dev/.github/blob/main/SECURITY.md).
