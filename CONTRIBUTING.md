# Contributing

Use the repository that owns the change. Public applications and shared packages live in [pgko](https://github.com/pgko-dev/pgko).

## Bug reports

Include reproduction steps, the affected commit or release, and expected and actual behavior. Add relevant logs or screenshots with credentials and personal data removed.

For vulnerabilities, use the [security policy](SECURITY.md).

## Pull requests

Follow the repository's README and `AGENTS.md`. Keep each PR focused and describe the resulting behavior and validation.

Run the checks relevant to the change. Update feature documentation in `docs/`; update READMEs when setup, common usage, or documentation links change.

Use Conventional Commit titles with the affected workspace directory as the scope, such as `fix(web): ...`. Use `repo` for repository-wide changes, such as `docs(repo): ...`.
