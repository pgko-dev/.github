# Contributing

Report bugs in the affected repository with reproduction steps and the expected and actual behavior.

Keep pull requests focused. Follow the setup instructions and checks in that repository's README, then describe the change and its validation.

Public apps and shared code belong in [pgko-dev/pgko](https://github.com/pgko-dev/pgko). Apps use local workspace packages; packages release together for external consumers.

For vulnerabilities, follow the [security policy](SECURITY.md).
