# Contributing

Report bugs in the affected repository with reproduction steps and the expected and actual behavior.

Keep pull requests focused. Follow the setup instructions and run the checks in that repository's README, then describe the change and how you tested it.

Shared code belongs in [pgko-dev/shared](https://github.com/pgko-dev/shared). Its packages release together; update consumer dependencies to the same release.

For vulnerabilities, follow the [security policy](SECURITY.md).
